PERFIL PAGE — BLANK SCREEN FIX DOCUMENTATION
============================================
Date: 2026-06-03
Scope: Only perfil-related files were modified (perfil.jsx, perfil-stats.jsx, abtme.jsx).

SUMMARY
-------
The profile route rendered a blank page because React crashed at runtime. The main
cause was referencing a component named AboutMe that was never imported or defined.
Additional issues prevented child components from receiving data even after the crash
was fixed.


FILE: src/pages/perfil.jsx
--------------------------

1. CHANGE: Import renamed from `pfStats` to `PfStats`.
   FUNCTION: Aligns the import name with the React component export (PascalCase).
   WHY: React components must use PascalCase in JSX. A mismatched import name made
        the intended component harder to wire correctly.

2. CHANGE: Removed invalid third value from useState destructuring
          (`const [perfil, setPerfil, setPf]` → `const [perfil, setPerfil]`).
   FUNCTION: Correct use of the useState hook API (state + setter only).
   WHY: useState returns exactly two values. A third variable was always undefined
        and indicated a misunderstanding that could cause bugs when used later.

3. CHANGE: Replaced `<perfil-stats />` with `<PfStats />` and passed props
          `perfil`, `setPerfil`, `isAdmin`.
   FUNCTION: Renders the profile header (photo, name, admin edit controls).
   WHY: Lowercase hyphenated tags are treated as unknown HTML elements, not React
        components, so the profile header never mounted.

4. CHANGE: Replaced `<AboutMe />` with `<Abtme />` (matching the actual import).
   FUNCTION: Renders the "About Me" section.
   WHY: `AboutMe` was never defined in this file, causing ReferenceError and a full
        page crash (blank white screen). This was the primary blank-page cause.

5. CHANGE: Updated main wrapper class from `perfil-page` to `profile-page`.
   FUNCTION: Applies layout styles from perfil.css to the page container.
   WHY: perfil.css defines `.profile-page`, not `.perfil-page`, so layout rules
        (width, padding, centering) were not applied.

6. CHANGE: Removed unused imports for Header and Footer.
   FUNCTION: Keeps the module clean; those components were not rendered in the JSX.
   WHY: Avoids confusion and unused-import noise; Header/Footer can be re-added
        when you want them on this page (requires your approval if outside perfil).


FILE: src/components/perfil-components/perfil-stats.jsx
-------------------------------------------------------

7. CHANGE: Props renamed from `Perfil`, `IsAdmin`, `SetPerfil` to `perfil`, `isAdmin`, `setPerfil`.
   FUNCTION: Receives profile state and admin flag from the parent page.
   WHY: The parent passed camelCase props; the child expected PascalCase names, so
        `perfil` was undefined inside the child and would crash on `perfil.name`.

8. CHANGE: Profile image field unified to `profileImage` (was `PfImage` on update/read).
   FUNCTION: Reads and updates the avatar URL in shared perfil state.
   WHY: Parent mock state uses `profileImage`; mismatched keys left the image broken
        after upload and on first render.

9. CHANGE: All internal references updated (`Perfil.name` → `perfil.name`, etc.).
   FUNCTION: Displays and edits name and image using the same object shape as the parent.
   WHY: Consistent data contract between perfil.jsx and perfil-stats.jsx.


FILE: src/components/perfil-components/abtme.jsx
----------------------------------------------

10. CHANGE: Component identifier `abtme` → `Abtme`; props `profile`/`setProfile` → `perfil`/`setPerfil`.
    FUNCTION: Receives and updates About Me text in parent state.
    WHY: Parent passes `perfil` and `setPerfil`; old prop names left `profile` undefined.

11. CHANGE: About text field unified to `aboutMe` (was `abtme` / `profile.abtme`).
    FUNCTION: Reads and saves the bio string in shared perfil state.
    WHY: Parent state in perfil.jsx uses `aboutMe`; mismatched keys showed empty text
         and saved to the wrong property.
